# AegisPay

**Intent-Aware Adaptive Scam Intervention for Mobile Financial Services**

AegisPay is being developed for the AI Dev Fest 2026 AI Hackathon under the
Trust & Risk Intelligence track.

The system aims to identify risky payment situations, understand beneficiary
network risk, selectively acquire scam context when useful, and recommend the
minimum effective intervention while balancing customer friction and
operational capacity.

> Development in progress.
